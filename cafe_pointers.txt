Part A:

What does a pointer store? How is that different from storing the price itself?

    - Pointers store the memory address of vars (variables). Storing the price itself only gives the function a copy of the var's value, but the pointer need to change the original value, so having the location address is good for when the var value needs to be changed.

After int *tag = &latte;, what do tag, *tag, and &latte each mean?

    - tag stores the memory address of latte. *tag means the value stored at that address, so it would be the current latte value. &latte means the memory address of the latte var, the address itself.

Why is it undefined behavior to dereference an uninitialized pointer? What should you initialize a pointer to if it does not yet have a target?

    - Uninitialized pointers don't know where to point to so the address points to an unknown address. dereference can cause undefined behaviors meaning that it will try to access random or invalid memory. If the pointer does not have a target then initialize it to NULL
